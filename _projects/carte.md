## 개요

"악동개발자" 팀에서 진행한 프로젝트입니다. 기존 컨테이너 오케스트레이션 도구는 학습 곡선이 높아 소규모 프로젝트나 단순한 애플리케이션 제작에는 부담이 된다는 문제의식에서, 최소 요구사항만 충족하는 경량형 컨테이너 서비스 "Carte"를 개발했습니다. 전반적인 프로젝트 기획과 요구사항 정의서 작성, 시스템 아키텍처 설계, 이미지·컨테이너 생명주기 구현을 담당했습니다.

## 기술 스택

`Go` `Ubuntu` `Linux Namespace` `Cgroup`

## 주요 기여

### 1. 리눅스 기반 이미지 생성

컨테이너 환경을 구축하기 위해 리눅스 기반의 이미지 생성 방안을 고민했습니다. 기본 우분투 이미지를 생성하는 스크립트를 작성하고, Docker 컨테이너 이미지가 여러 레이어로 구성된다는 개념을 학습해 효율적인 이미지 관리 방법에 반영했습니다.

- Namespace 설정을 통해 프로세스를 격리했습니다.
- Cgroup 설정을 통해 CPU·메모리 등 리소스를 제한했습니다.

### 2. 컨테이너 생애주기 기반 설계

컨테이너 생성-실행-종료 과정에 맞춘 최적의 컨테이너 생성 방안을 고려해, 생애주기(create / start / stop / rm)에 맞춘 명령어 구조로 Carte Engine을 설계했습니다. 이를 바탕으로 컨테이너 생성, 실행, 중지, 삭제와 이미지 실행·명령 수행 기능을 구현했습니다.

### 3. 컨테이너 네트워크 구성

컨테이너 내부에서 네트워크 인터페이스가 보이지 않는 문제를 해결하기 위해 네트워크 통신 과정을 살펴보고, veth를 활용해 네트워크 연결을 구성하는 방식으로 네트워크 분리를 구현했습니다.

## 결과

- Docker 대비 컨테이너 시작 시간을 273ms → 31ms로, 메모리 사용량을 18.2MiB → 7.28MiB로 단축했습니다.
- Namespace·Cgroup 기반 프로세스 격리 및 리소스 제한 기능을 구현했습니다.
- 이미지 실행과 명령 수행이 가능한 경량 컨테이너 서비스를 완성했습니다.
- Kubernetes 클러스터 환경에서의 노드 간 통신·스케줄링 개념을 함께 학습하며, 복잡한 분산 환경에서의 운영 방식에 대한 이해를 넓혔습니다.
