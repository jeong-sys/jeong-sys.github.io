## 개요

국가재난안전교육원의 대표 홈페이지, 통합관리시스템, 교육관리시스템, 종사자시스템 총 4개 시스템에 대한 유지보수 및 기능 개선을 담당했습니다. 특히 종사자시스템에서는 기관별 통계 관리 체계를 계정 구조부터 새로 설계했고, 통합관리시스템에서는 공용차량 관리 시스템을 단독으로 설계·구축하며 공통 컴포넌트 분리 등 구조 개선 경험을 쌓았습니다.

## 기술 스택

`Java 8` `Spring Legacy (XML 설정)` `Spring MVC` `MyBatis` `JSP` `Servlet` `eGovFrame` `Cubrid` `Tomcat` `SVN` `Maven`

## 주요 기여

### 1. 종사자시스템 — 기관별 통계 관리 체계 설계

중앙부처와 지자체는 통계 입력 방식과 항목 체계가 서로 달랐으나, 하나의 통계 화면에서 양쪽 데이터를 모두 조회해야 한다는 요구사항이 있었습니다.

**설계**
- 기관 유형 구분이 계정 단위에서부터 시작되도록 기관별 별도 계정 체계를 부여했습니다.
- 통계 테이블 하나에서 상위기관은 상위코드만, 하위기관은 상위코드+하위코드를 함께 갖도록 설계해, 테이블 분리 없이 계층 관계를 코드 체계만으로 표현했습니다.

**문제**
설계는 단순해졌지만 두 기관 유형의 실제 운영 방식이 정반대라는 문제가 드러났습니다.

| 기관 유형 | 운영 특성 | 필요한 처리 |
|---|---|---|
| 상위기관(중앙부처) | 신규 등록 외에는 데이터가 거의 고정 | 변경 시 `UPDATE` |
| 하위기관(지자체) | 기관·담당자가 수시로 추가·제외됨 | `INSERT` / `DELETE` |

같은 테이블에서 "상위기관 관리자 수정"과 "하위기관 관리자 추가·삭제"가 서로 다른 로직으로 동작해야 해 쿼리와 처리 흐름이 복잡해졌습니다.

**해결**
상위코드·하위코드 존재 여부를 기준으로 분기 처리 로직을 구성해, 같은 테이블에서도 상위기관 케이스(UPDATE)와 하위기관 케이스(INSERT/DELETE)를 명확히 구분해 처리하도록 구현했습니다. 그 결과 상위기관은 1개 행, 하위기관은 기본 행 + 담당자 지정 시 추가되는 행 구조를 가지게 되어, 기관 조회와 수시로 바뀌는 담당자 관리 모두를 안정적으로 지원할 수 있었습니다. 이 밖에 기관별 통계 담당자 관리, 기관별 통계 입력, 중앙부처·지자체 이수 현황 조회 기능도 함께 구현했습니다.

### 2. 통합관리시스템 — 공용차량 관리 시스템 구축

차량 관리와 사용자 신청 프로세스 전반을 처음부터 설계·구축했습니다.

- 차량 관리 CRUD, 사용자 신청 CRUD 전 기능을 개발했습니다.
- Java 기반 엑셀 다운로드 기능을 구현했습니다.
- 외부 SMS 솔루션 API를 연동해 신청 시 사용자·관리자에게 자동 문자를 발송, 신청부터 알림까지의 흐름을 자동화했습니다.
- 테이블 구조를 직접 설계하며 데이터 모델링을 주도적으로 수행했습니다.

개발 진행 중 "A 페이지와 B 페이지에서 동일한 화면·기능이 노출되어야 한다"는 요구사항 변경이 발생했습니다. 각 페이지에 로직을 복제하는 대신 파일 처리 로직을 페이지 간 공통 컴포넌트로 분리해, 중복 코드를 제거하고 이후 동일 요구가 추가되어도 확장 가능한 구조로 정리했습니다.

### 3. 통합관리시스템 — 배너·생활관 관리 기능

기존 PC용 배너 이미지 처리 구조에 모바일용 이미지를 추가하는 작업에서, 파일이 리스트 형태로 한꺼번에 들어오며 기존 단일 파일 처리 로직으로는 PC·모바일 이미지가 서로 겹치거나 잘못 매핑되는 문제가 발생했습니다. Java 단에서 파일의 용도를 식별해 분기 저장하는 로직을 추가해, 기존 데이터 구조와 처리 흐름을 깨지 않으면서 이미지 2종 동시 관리라는 신규 요구사항을 점진적으로 확장해 반영했습니다.

- 생활관 배정 검색 조건에 장애인 여부, 임산부 여부, 지역 조건을 추가하고 MyBatis 동적 SQL로 다중 조건 조합에 대응했습니다.
- 관리자용 식수 인원 조회 기능과, 사용자 신청 기능에 연동되는 통계 화면을 구현했습니다.

### 4. 대표 홈페이지 / 교육관리시스템 — 화면 및 신청 프로세스 개선

- 배너 영역에 화면 크기별로 다른 이미지를 노출하는 분기 처리 로직을 CSS breakpoint 기준으로 직접 구현했습니다.
- 교수진 소개 페이지에 카테고리 필터(재난안전 / 민방위 / 안전훈련)를 JSP·jQuery 기반 동적 필터링으로 추가했습니다.
- 사용자단 식수 신청·변경 기능을 개발했습니다.
- 생활관 신청 시 지역·장애인 여부·임산부 여부 조건을 확장하고 문자 발송 안내 문구를 개선했습니다.

## 결과

- 계층 구조(상위-하위)가 다른 기관 데이터를 단일 테이블로 관리하면서도, 기관 유형별 실제 운영 방식에 맞는 데이터 처리 로직을 구현했습니다.
- 공용차량 관리 시스템을 단독으로 설계·구축하며, 요구사항 변경에 대응한 공통 모듈 리팩토링과 테이블 설계 경험을 쌓았습니다.
- 4개 시스템의 유지보수를 통해 레거시 공공기관 시스템의 운영 및 장애 대응 경험을 폭넓게 쌓았습니다.
