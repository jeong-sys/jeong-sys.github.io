## 개요

"악동 개발자" 팀에서 메타버스 플랫폼 제작을 목표로 진행한 프로젝트입니다. 기존 메타버스 플랫폼이 개발 단계에서 임포트된 에셋만 활용할 수 있다는 한계를 해결하기 위해, 사용자가 직접 3D 에셋을 추가해 자유롭게 맵을 구성할 수 있는 Login/Asset/Map/Game 서버를 구축했습니다. 백엔드 팀장으로 개발 범위 산출, 일정 관리, 아키텍처·ERD 설계를 담당했습니다.

## 기술 스택

`Go` `Docker` `MySQL` `MongoDB`

## 주요 기여

### 1. Asset 데이터 모델링

에셋 데이터를 어떤 구조의 DB에 저장할지, 카테고리와 관계를 어떻게 설계할지 고민이 있었습니다. Category를 세부적으로 분류하고 고유 ID를 매핑해 관계형 데이터베이스(MySQL) 모델로 구성했습니다.

### 2. Map 데이터 저장 방안

JSON 형태로 들어오는 맵 데이터를 유실 없이 저장할 방법이 필요했습니다. NoSQL 데이터베이스(MongoDB)를 채택해 JSON 구조를 그대로 저장하도록 설계했습니다.

### 3. 컨테이너 기반 운영

Login/Asset/Map/Game 여러 서버를 어떤 환경에서 운영할지 결정해야 했습니다. Docker Compose를 활용해 서버 환경을 구성하고, 컨테이너 기반으로 게임 서버를 구축·운영했습니다.

## 결과

- Login/Asset/Map/Game Server로 구성된 게임 서버를 Docker 환경에서 구축·운영했습니다.
- 실제 학생을 대상으로 운영 테스트를 진행하고 수업을 통해 사용법을 안내하며, 실 사용자 피드백의 중요성을 체감했습니다.
- TCP/UDP 프로토콜과 여러 데이터베이스의 장단점을 실전 경험을 통해 체득했습니다.
