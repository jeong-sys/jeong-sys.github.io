## 개요

꾸준한 학습을 장려하는 "우.아.모" 팀에서 진행한 프로젝트입니다. 혼자 학습하다 보면 의지력이 흔들리기 쉽다는 문제의식에서 출발해, 스터디 팟(포인트 배팅, 채팅), 학습 게시판, 코스튬 구매 등 재미와 경쟁 요소를 더해 사용자가 자발적으로 학습에 참여하도록 돕는 플랫폼입니다. 이미지 관리, 코스튬 관리, 배포를 담당했습니다.

## 기술 스택

`Spring Boot` `Java` `MariaDB` `MongoDB` `Redis` `WebSocket` `SSE` `Grafana` `Docker` `EC2` `RDS` `S3`

## 주요 기여

### 1. 이미지 관리 체계 설계

게시판, 팟 인증, 코스튬 등 여러 도메인에서 이미지를 다뤄야 했는데, 테이블마다 이미지 id를 저장하는 방식은 관리가 비효율적이었습니다.

- 이미지 테이블에서 Enum 클래스와 각 테이블의 id를 활용해 S3 경로와 매핑하는 구조로 재설계했습니다.
- S3 기반 이미지 업로드·수정·삭제 기능을 게시판, 팟 인증, 코스튬 전반에 구현했습니다.

또한 QueryDSL을 적용하는 과정에서 서비스 레이어가 Repository에 직접 의존하는 구조적 문제를 발견해, 서비스 로직과 데이터 접근 로직을 명확히 분리하는 리팩토링으로 계층 구조를 개선했습니다.

### 2. 코스튬 관리 및 결제 연동

코스튬 등록·조회·수정·삭제 CRUD를 구현하고, Toss Open API를 연동해 코스튬 결제 기능을 구현했습니다.

### 3. 배포 자동화 및 무중단 배포

배포 시 다운타임이 발생하는 문제를 해결하기 위해 무중단 배포 전략을 검토했습니다.

- GitHub Actions 기반 CI/CD 파이프라인을 구축하고 Docker로 컨테이너화했습니다.
- Nginx 컨테이너화를 활용한 Blue-Green 배포 방식을 도입해 무중단 배포를 구현했습니다.
- EC2 인스턴스를 직접 사용해 서버 환경을 설정·관리하며 환경 변수 관리와 권한 설정의 중요성을 익혔습니다.

## 결과

- S3 기반 이미지 관리 체계와 코스튬 결제 기능을 안정적으로 구현했습니다.
- GitHub Actions CI/CD와 Blue-Green 무중단 배포로 자동 배포 환경을 구축해 개발 생산성을 높였습니다.
- Git-Flow 전략과 PR 코드 리뷰를 통해 팀원 간 원활한 협업 경험을 쌓았습니다.
